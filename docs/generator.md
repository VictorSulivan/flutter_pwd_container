# Générateur

Indépendant du coffre : aucun appel Firebase, aucun stockage. `Random.secure()`.

Options : longueur 8–64, majuscules, minuscules, chiffres, symboles. Au moins un caractère de chaque type coché.

Accès :

- bouton **Générateur** sur l’écran maître (`/unlock`), sans ouvrir le coffre
- bouton **Générer** dans l’en-tête de la liste, plus **Ouvrir le générateur** si le coffre est vide
- carte **Générateur** au-dessus des fiches
- bouton **Générer** dans le formulaire de fiche (remplit le champ)

Copie : presse-papier vidé après 30 s (comme les fiches).
